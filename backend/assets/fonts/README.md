# Cover fonts

Vendored from the Google Fonts repository on 20 November 2026:
https://github.com/google/fonts/tree/main/ofl

- Noto Sans: `ofl/notosans/NotoSans[wdth,wght].ttf`
- Noto Sans Bengali: `ofl/notosansbengali/NotoSansBengali[wdth,wght].ttf`
- Noto Sans Arabic: `ofl/notosansarabic/NotoSansArabic[wdth,wght].ttf`
- Noto Sans Devanagari: `ofl/notosansdevanagari/NotoSansDevanagari[wdth,wght].ttf`

Each unmodified font has its accompanying SIL Open Font License file. These exact bytes serve both browser previews and Chromium cover exports. No external font service is contacted at render time. Cover font coverage is limited to these families; review script support before selling a cover. Broader font coverage is S08 work.
